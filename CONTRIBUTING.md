# Diretrizes de Contribuição

Obrigado por considerar contribuir com o **Dashboard Template**! Este projeto utiliza componentes do [ShadcnUI](https://ui.shadcn.com/) com modificações, e sua colaboração é essencial para melhorar o template.

## Como Contribuir
1. Faça um fork do repositório.
2. Crie uma branch para sua alteração (`git checkout -b feature/nova-feature`).
3. Commit suas alterações com mensagens claras (`git commit -m 'Adiciona nova feature'`).
4. Envie para o repositório remoto (`git push origin feature/nova-feature`).
5. Abra um Pull Request descrevendo suas alterações.

## Tipos de Contribuições
- Adicionar novas variantes ou melhorias a componentes (ex.: novas opções para o `Button`).
- Corrigir bugs em telas ou componentes.
- Criar novas telas ou funcionalidades para o dashboard.
- Melhorar a documentação ou exemplos na galeria `components-guide/`.

## Padrões de Código
- Use TypeScript para todos os arquivos.
- Siga as convenções do ESLint/Prettier (se configurado).
- Mantenha o aviso de licença MIT nos arquivos derivados do ShadcnUI.
- Teste suas alterações localmente antes de enviar.

## Componentes Derivados do ShadcnUI
Alguns componentes, como o `Button`, são baseados no ShadcnUI com modificações. Ao contribuir com esses componentes:
- Respeite a licença MIT do ShadcnUI (inclua o aviso de direitos autorais nos arquivos modificados).
- Documente claramente quaisquer alterações no `README.md` ou em arquivos de documentação.

## Reportando Bugs
- Abra uma issue descrevendo o problema, incluindo:
  - Passos para reproduzir.
  - Comportamento esperado.
  - Capturas de tela (se aplicável).

## Código de Conduta
Respeite todos os colaboradores e siga nosso [Código de Conduta](CODE_OF_CONDUCT.md).
