# Código de Conduta

## Nosso Compromisso

Nós, como mantenedores e colaboradores do **Dashboard Template**, estamos comprometidos em proporcionar um ambiente acolhedor, seguro e inclusivo para todos, independentemente de idade, identidade de gênero, orientação sexual, deficiência, aparência física, etnia, religião, nível de experiência, ou qualquer outra característica pessoal.

Nosso objetivo é criar uma comunidade onde todos possam contribuir com ideias, código e feedback de forma respeitosa e colaborativa.

## Nossos Padrões

Exemplos de comportamentos que contribuem para um ambiente positivo incluem:
- Usar uma linguagem acolhedora e inclusiva.
- Respeitar diferentes pontos de vista e experiências.
- Aceitar críticas construtivas com graça.
- Focar no que é melhor para a comunidade.
- Demonstrar empatia e apoio aos outros membros.

Exemplos de comportamentos inaceitáveis incluem:
- Uso de linguagem ou imagens sexualizadas, ou avanços sexuais indesejados.
- Comentários ofensivos, insultos ou ataques pessoais.
- Assédio público ou privado.
- Publicação de informações privadas de outros (ex.: e-mails, endereços) sem permissão.
- Qualquer conduta que possa ser considerada inadequada em um ambiente profissional.

## Responsabilidades de Aplicação

Os mantenedores do projeto são responsáveis por esclarecer e aplicar os padrões de comportamento. Eles têm o direito e a responsabilidade de remover, editar ou rejeitar comentários, commits, issues, pull requests ou outras contribuições que não estejam alinhados com este Código de Conduta. Em casos graves, os mantenedores podem banir temporária ou permanentemente qualquer colaborador por comportamentos inadequados.

## Escopo

Este Código de Conduta aplica-se a todos os espaços do projeto, incluindo o repositório GitHub, issues, pull requests, discussões e qualquer evento ou canal de comunicação relacionado ao projeto. Ele também se aplica quando um indivíduo representa o projeto em outros espaços, como eventos ou redes sociais.

## Reportando Violações

Se você presenciar ou for vítima de comportamento inaceitável, por favor, reporte entrando em contato com os mantenedores do projeto em `onogueiradev@gmail.com`. Todos os relatos serão tratados com confidencialidade e revisados o mais rápido possível.

Você também pode abrir uma issue no repositório, marcando-a como confidencial, se preferir. Os mantenedores investigarão o caso e tomarão as medidas apropriadas, que podem incluir advertências, remoção de conteúdo ou banimento do colaborador.

## Padrões Técnicos e Práticas de Código

Além dos padrões comportamentais, nós valorizamos a qualidade técnica e a consistência do código. Para manter um projeto de alta qualidade e facilitar a colaboração, pedimos que todos os contribuidores:

- **Sigam as convenções de código**: Respeitem as configurações do ESLint e as convenções estabelecidas no projeto. Isto inclui:
  - Uso de ponto e vírgula no final das instruções
  - Preferência por aspas simples para strings
  - Indentação com 2 espaços
  - Nomenclatura clara e descritiva para variáveis e funções
  - Tipagem adequada em TypeScript

### Executando o ESLint

1. Para verificar problemas no código:
   ```bash  
   npm run lint
   ```

2. Para corrigir automaticamente os problemas encontrados:
   ```bash
   npm run lint:fix
   ```

- **Documentem adequadamente**: Adicionem comentários apropriados para código complexo e atualizem a documentação quando necessário.

- **Respeitem os padrões arquiteturais**: Mantenham a estrutura de pastas e a separação de responsabilidades do projeto.

- **Evitem código duplicado**: Busquem reutilizar componentes e funções existentes antes de criar novos.

- **Sejam receptivos ao feedback técnico**: Assim como com feedback comportamental, estejam abertos a sugestões de melhorias técnicas de outros colaboradores.

Acreditamos que código limpo e consistente é uma forma de respeito aos outros colaboradores e usuários do projeto. Ao seguir esses padrões técnicos, você não apenas melhora a qualidade do Dashboard Template, mas também facilita a contribuição de outros desenvolvedores.

Lembre-se: todos começamos em algum lugar. Se você não tem certeza sobre alguma dessas práticas ou precisa de ajuda para implementá-las, não hesite em perguntar - estamos aqui para apoiar uns aos outros.

## Consequências

Comportamentos que violem este Código de Conduta podem resultar em ações como:
- Remoção de comentários ou contribuições.
- Bloqueio temporário ou permanente de participação no projeto.
- Outras medidas consideradas necessárias pelos mantenedores.
